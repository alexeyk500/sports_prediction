This manifest removes icon-design discretion from the implementation.

| UI role | Required source |
|---|---|
| Prize/Cup trophy | `icons/trophy.svg` |
| USDT asset badge | `icons/usdt.svg` |
| TRON network badge | `icons/tron.svg` |
| Card/detail chevron | `icons/chevron-right.svg` |
| Copy wallet/hash | `icons/copy.svg` |
| Safety/info notice | `icons/info.svg` |
| External link | `icons/external-link.svg` |
| Claim sheet close | Existing canonical Goalstery control, otherwise `icons/close.svg` |
| Contact support help glyph | `icons/help.svg` |
| Page back | Existing canonical Goalstery control, otherwise `icons/back.svg` |
| Overflow/more | Existing canonical Goalstery control, otherwise `icons/more.svg` |
| Goalstery crown/logo | Existing repository asset/component only |
| Bottom navigation | Existing repository assets/components only |

Do not recreate global Goalstery branding or navigation from the raster mockup. The mockup's bottom navigation is conceptual and may not match the current product navigation.

Monochrome SVGs use `currentColor` so their colors must come from existing semantic theme tokens. Branded USDT/TRON SVGs carry their intended brand colors.
